CreatorOS

A creator sourcing & outreach engine. Paste any TikTok profile link and watch it extract followers, engagement and contact info — live, in your browser. Then score everyone against a brand profile and build the outreach batch.

This demo makes real API calls — profile extraction and keyword sourcing hit TikTok data through the free tikwm API, right from this page. Under the Hood

Same engine that runs my real pipeline

01 · discover

Free-API sourcing

Cursor-paginated keyword search plus auto-expansion on co-occurring hashtags. One run pools 100–300 creators, zero API cost.

02 · qualify

Brand-fit rubric

Keyword match, audience-size fit, engagement quality, reachability — minus spam signals. Thresholds are business policy, editable without touching code.

03 · reach

Outreach with guardrails

Personalized Gmail batches with preview-first sending, dry-run default, daily caps, pacing and opt-out — the parts a public demo rightly can't do.
